## ⭐ Featured Projects

### 🧠 CRRF — Facial Emotion Recognition

**[CRRF](https://github.com/ivanBasCub/CRRF)** is a Deep Learning and Computer Vision project focused on automatic facial emotion recognition.

The project explores image, video and camera-based recognition using convolutional neural networks and image-processing techniques.

**Technologies:** Python · PyTorch · OpenCV · Albumentations · CNN · Jupyter

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge\&logo=github)](https://github.com/ivanBasCub/CRRF)

### 🔐 Corp Auth

**[Corp Auth](https://github.com/ivanBasCub/Auth)** is a web application developed for managing authentication and functionality related to an EVE Online corporation.

The project combines a Django backend with asynchronous task processing and containerization.

**Technologies:** Python · Django · Celery · Docker · Bootstrap

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge\&logo=github)](https://github.com/ivanBasCub/Auth)

### 🎲 Imp Pact 5e

**[Imp Pact 5e](https://github.com/ivanBasCub/Imp_Pact_5e)** is a web application for managing Dungeons & Dragons 5e characters and related content.

It was developed as my **Final Degree Project**, combining a React frontend with Firebase services.

**Technologies:** React · JavaScript · Firebase · Firestore · HTML · CSS · Bootstrap

🌐 **[Live Application](https://impact5e.web.app/)**

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge\&logo=github)](https://github.com/ivanBasCub/Imp_Pact_5e)

### 🏆 Battle Zone

**[Battle Zone](https://github.com/ivanBasCub/BattleZone)** is a web application for creating and managing video game tournaments.

It uses Django to handle the application's backend, data models and tournament-related functionality.

**Technologies:** Python · Django · SQLite

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge\&logo=github)](https://github.com/ivanBasCub/BattleZone)
